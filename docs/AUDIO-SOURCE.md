# 《空席》证词录音来源与验证

## 来源

- 推理代码：[QwenLM/Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)，`qwen-tts==0.1.1`，Apache-2.0。
- 原创角色声线：[Qwen3-TTS-12Hz-1.7B-VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)，模型卡标注 Apache-2.0。
- 跨章节声音保持：[Qwen3-TTS-12Hz-0.6B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)，模型卡标注 Apache-2.0。
- 检查：[faster-whisper](https://github.com/SYSTRAN/faster-whisper) small，CPU int8，中文，beam_size=5。

2026-11-02 在已有 CPU 环境本地运行；没有购买、充值、付费 API 或信用卡试用。下载后生成使用本地模型，不调用云端语音服务。仓库仅分发生成录音，不包含模型权重、环境或缓存。模型许可证的标注是工具/权重来源说明，不是对生成作品的独占权或不侵权保证。

## 12 个虚构成年角色

首章根据既有人设的年龄、声线、性格和表演方向分别设计声音；第二、三章通过 Base 复用这些自行生成的参考录音。没有使用真人、明星或声优样本，也没有要求模仿某位真实人物。表达方向为自然、克制的心理悬疑证词，不以夸张反派腔、幼态腔或粗暴升降音调区别角色。

每段只读原始证词。时间如 `22:15` 规范化为“二十二点十五分”，不更改逻辑、事实、人物、否定词或连接词。manifest 的 `text` 保留游戏原文，用于防止文字变更后播放旧录音。

## 文件

36 段、3 章 × 12 人，单声道 24 kHz / 96 kbps MP3。以 FFmpeg loudnorm 统一响度目标至 -18 LUFS、峰值目标 -2 dBTP。文件名为 `<chapterId>-<speaker>.mp3`；不含标签说明、提示词或额外剧情。

## 已做的验证与边界

- 对所有 36 段生成 WAV 做本地 ASR，逐条比对证词含义、否定、且/或、同真同假、条件、人物、颜色及时间；ASR 原始转写保留在配套 JSON 中。
- 首轮发现 `empty-seat-1:11` 的“红信封/蓝信封”差异、`empty-seat-3:4` 的“启用/使用”差异；两段已重生成并重新转写确认。`empty-seat-3:6` 也重生成改善清晰度。
- 检查时长和 WAV 波形削波；没有发现截断、长篇重复、额外台词或削波。
- ASR 中仍有“周恒/周衡”“无限电/无线电”“一键/一件”等同音字，以及小数点式时刻转写；这些不等同于听到的读音错误。检查不把 ASR 当作绝对真值。
- **未完成真人主观试听，不能宣称已认证情绪表现、音色辨识度或每个声调完美。**这是模型生成的角色录音，不是专业演员实录。最终听感可在游戏内直接播放评价。
