# 人物配音与播放架构

## 配音方向

十二名角色的年龄、经历与说话习惯记录于`src/data/puzzles.json`的`characters`。`voiceProfile.direction`用于制作配音，`description`是玩家可见的简洁说话方式；这些不是额外逻辑证据，也不暗示谁在隐瞒。不能仅靠随机调音高/速度把同一个音色冒充十二位角色。

本分支包含36段本地生成的角色配音，绑定于`src/audio/recordings.js`，文件位于`public/audio/`。全部完成解码与逐句自动识别复核，其中3段发现关键字问题后已重新生成并复核。总时长约300秒，MP3合计约3.6MB。详见[来源记录](AUDIO-SOURCE.md)和[逐段审计](audio-audit.json)。没有进行主观听感评审，不把自动识别通过等同于真人级表演或跨设备听音认证。

## 生成来源

免费、在现有CPU环境本地运行，无付费API或第三方计费接口：

- [Qwen3-TTS 官方代码](https://github.com/QwenLM/Qwen3-TTS)，Python包`qwen-tts` 0.1.1。
- [Qwen3-TTS-12Hz-1.7B-VoiceDesign](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign)，模型卡许可证Apache-2.0。
- [Qwen3-TTS-12Hz-0.6B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)，模型卡许可证Apache-2.0。

先按人物方向生成原创虚构成年声线，再以该原创声音作为后续章节的参考。没有采集真人、演员或公众人物声纹。模型权重和生成环境不随网页项目分发；玩家运行游戏不需要安装Python/TTS模型。

## 录音绑定

清单键为`章节id:人物id`，值包含`src`（仅项目内`/audio/`路径）与`text`（未经改写的原始完整证词）。只有清单原文与当前题目逐字一致时才使用录音，避免改题后继续播旧台词。

允许把19:05规范读成“十九点零五分”，不允许改动否定、条件、且/或、恰好一个、时间或人物关系。文字显示、真值表达式与答案不会经过朗读格式化。

## 播放与后备

- 必须明确点击播放，不自动播放。
- 同时只播放一位；点击同一位停止，另一位替换。
- 切章、重查、重置、页面隐藏与卸载均停止。
- 录音失败会提示，只有再次明确点击才使用系统中文后备朗读。
- 系统后备优先设备提供的自然普通话音色，支持手动选音色；音色标记不保证设备实际音质。
- 系统后备保留设备差异，不能保证固定音色或情绪表演。

单元测试覆盖生命周期、陈旧回调隔离、文字匹配、错误与超时。自动语音识别可帮助核对语义，但不等于主观听感评审，也不能保证每台Windows/Android/iOS设备的输出效果相同。
